# Codex Reset

查看 Codex 额度重置记录、28 天活动日历、最新动态和服务状态。
静态 HTML / CSS / JavaScript，零依赖、无需构建，Node 18+ 即可运行。

```bash
npm start            # http://localhost:4173
npm run check        # 模块语法与日历日期/记录状态检查
```

## 页面

| 路径 | 内容 |
| --- | --- |
| `/` 概览 | 最近一次重置、24/48 小时预测、可切换月份的重置日历、选中日期的详情、分类动态 |
| `/timeline` 重置记录 | 重置间隔图、分类筛选、时区切换和可排序的历史记录 |
| `/status` 服务状态 | 各项 Codex 服务的状态与故障记录 |
| `/vigil` 一起等重置 | 等待人数、公开名单、历史重置时段和常见问题 |

支持中文 / English、浅色 / 深色模式和手机布局。服务状态和等待页面可从页脚进入。

## 日历与记录

- 活动范围为 2026 年 10 月 5 日至 11 月 1 日。星期与日期按美国太平洋时间排列，帖子时间按访问者的本地时区显示。
- 所有屏幕使用同一个日历组件；点击日期在页面内查看详情，可以切换月份或回到今天。
- 分别显示额度重置、备用额度、产品更新、待确认重置、暂无记录和未到日期。
- 重置公告与生效记录分开处理；没有生效记录时不计入已确认重置。未标明活动天数的日常帖子不计入活动更新。
- 相同数据的轮询保留选中日期和已展开的动态原文。

## 数据来源

数据来自 `codex-reset.com` 的公开只读 JSON 接口，由本地 `/api/*` 代理。
代理有短期缓存，页面会自动刷新数据。接口暂时不可用时显示已获取的记录和错误提示。
此项目不向上游提交投票、等待登记或互动。预测仅供参考，不代表官方承诺。

非官方项目，与 OpenAI 无关。
