# Codex Reset

查看 Codex 额度重置记录、28 天活动日历、最新动态和服务状态。
静态 HTML / CSS / JavaScript，零依赖、无需构建，Node 18+ 即可运行。

```bash
npm start            # http://localhost:4173
npm run check        # 模块语法与日历日期/记录状态检查
npm run check:server # HTTP 路由、健康检查与异常请求隔离
npm run check:deploy # 发布验证器的版本、资源和接口异常检查
```

推送到 `main` 后由 GitHub Actions 自动检查并部署，也可手动运行 `npm run deploy`。
部署结构、版本核对和回滚见 [DEPLOY.md](DEPLOY.md)。
线上地址：[codex-reset.opentunnel.asia](https://codex-reset.opentunnel.asia/)。

## 页面

| 路径 | 内容 |
| --- | --- |
| `/` 概览 | 最近一次重置、24/48 小时预测、可切换月份的重置日历、选中日期的详情、分类动态 |
| `/timeline` 重置记录 | 重置间隔图、分类筛选、时区切换和可排序的历史记录 |
| `/status` 服务状态 | 各项 Codex 服务的状态与故障记录 |
| `/vigil` 一起等重置 | 等待人数、公开名单、历史重置时段和常见问题 |

支持中文 / English、浅色 / 深色模式和手机布局。服务状态和等待页面可从页脚进入。

## 日历与记录

- 活动范围为 2026 年 10 月 5 日至 11 月 1 日。默认按 Tibo 明示的 Day 1–28 排列，不因访问者时区改变活动日期；例如 Day 12 始终对应 10 月 16 日。
- 可切换“按发生日期”，按实际事件时间、在所选时区归档；允许某天没有事件、另一天有多条。
- 详情的发布、确认和生效时间统一使用页面显示时区，默认跟随设备，也可切换北京时间、美国太平洋时间或 UTC。
- 活动内容同时读取公开 feed 的 `tweets` 和 `radar_context`。后者中的产品更新用于活动和动态展示，不加入重置信号或预测。两路按帖子 ID 去重，本地早期记录作为补充。
- “Tibo 最新动态”使用两路消息合并后的展示列表，按实际发布时间倒序、去重并保留翻译；只更新 `radar_context` 时列表也会刷新。展示列表与重置信号来源分开，不将普通动态当作已确认重置。
- 分别显示额度重置、备用额度、产品更新、待确认重置和未到日期；无来源时保留缺失状态，不推断或填造更新。
- 重置公告与确认记录分开处理，事件优先使用生效时间。同一天可展示多条事件；切换排列方式时，选中的事件跟随所在日期。
- 相同数据的轮询保留选中日期和已展开的动态原文。

## 数据来源

数据来自 `codex-reset.com` 的公开只读 JSON 接口，由本地 `/api/*` 代理。
代理有短期缓存，页面会自动刷新数据。接口暂时不可用时显示已获取的记录和错误提示。
此项目不向上游提交投票、等待登记或互动。预测仅供参考，不代表官方承诺。

非官方项目，与 OpenAI 无关。
